> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The World Cup pages (qualifying, groups, knockout, teams), the play wiring on the 5b engine, clinch bars, the Tournament MVP pick, and the `summary.json` write at the end.

**Architecture:** Pure helpers in `web/engine/wc/` (`writes.ts`, `clinch.ts`, `mvp.ts`, `summary.ts`) plus pages in `web/app/wc/`. **Tech Stack:** TypeScript 5, React 18, React Router 6, zod 3 (strict), Vitest 2 + jsdom.

```ts
import type { CalendarFile, QualifyingFile, RostersFile, WorldCupFile } from '../shared/types';
import type { WcKey, WcResult } from './state';

type WcDocs = { calendar: CalendarFile; rosters: RostersFile; qualifying?: QualifyingFile | null; worldCup?: WorldCupFile | null };

/** The documents a wc move changed, as `{path, doc}` writes (same order as `changed`). */
export function wcWrites<S extends WcDocs>(result: Extract<WcResult<S>, { ok: true }>): { path: string; doc: unknown }[] {
  const s = result.state;
  const one = (k: WcKey): { path: string; doc: unknown } => {
    switch (k) {
      case 'calendar': return { path: 'calendar.json', doc: s.calendar };
      case 'rosters': return { path: `leagues/fbawc/S${s.rosters.season}/rosters.json`, doc: s.rosters };
      case 'qualifying': return { path: `leagues/fbawc/S${s.qualifying!.season}/qualifying.json`, doc: s.qualifying };
      case 'worldcup': return { path: `leagues/fbawc/S${s.worldCup!.season}/worldcup.json`, doc: s.worldCup };
    }
  };
  return result.changed.map(one);
}
```

### Task 2: Clinch engine and `Clinch.tsx` kinds

**Files:** Create `engine/wc/clinch.ts`, `clinch.test.ts`; Modify `app/components/Clinch.tsx`, `Clinch.test.tsx`, the clinch CSS (grep `clinch-eliminated` under `web/app` to find it).

**Interfaces:**
- Produces: `type WcClinch = 'qualified' | 'advanced' | 'eliminated'`; `qualifyingClinch(q: QualifyingFile): Record<string, WcClinch | null>` (keys: all 15 auto and 70 field teams); `groupClinch(wc: WorldCupFile, group: string): Record<string, WcClinch | null>` (keys: the group's 4 teams). In `Clinch.tsx`: `ClinchKind` gains `'qualified' | 'advanced'`; the league type gains `'fbawc'`; `clinchLabel` returns "Qualified" and "Advanced to knockouts"; `ORDER` places `qualified` and `advanced` first. `RankCell` and `ClinchLegend` accept `league: 'fba' | 'fbad2' | 'fbawc'`.

**Rule (conservative: wins only, ties stay open).** For a table of teams with current wins `w` and remaining scheduled games `r`, `maxW = w + r`. Remaining games: qualifying uses `q.schedule.slice(q.games.length)`; a group uses `wc.schedule.slice(wc.groupGames.length)` filtered to games whose two teams are both in the group. The cut `K` is 49 of 70 for qualifying and 2 of 4 for a group.
- A team is **clinched** when fewer than K others have `maxW >= its w`.
- A team is **eliminated** when at least K others have current `w > its maxW`.
- Auto teams are always `'qualified'`.
- When the table is finished, use the final order instead. Qualifying finished means `q.advanced.length > 0`: `q.advanced` are `'qualified'` and the other field teams `'eliminated'`. A group with no remaining games: the top two from `groupTable` are `'advanced'` and the other two `'eliminated'`.

  - (b) with no games played nobody else is clinched or eliminated (all `null`);
  - (c) a team with 6 wins after 6 games is `'qualified'`; a team with 0 wins after 6 played, with 49 others already holding more wins, is `'eliminated'`;
