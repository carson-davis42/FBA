> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The data and engine for the S79 World Cup: city→country table, roster derivation, qualifying, group stage, knockout, schemas, calendar steps.

**Architecture:** Pure TypeScript under `web/engine/wc/`. Every random choice uses an injected `Rng` (`engine/d2/random.ts`). **Tech Stack:** TypeScript 5, zod 3 (strict), Vitest 2 (globals off).

### Task 2: Schemas for qualifying and World Cup

**Files:** Modify `web/engine/shared/types.ts`, `web/engine/shared/schemaRegistry.ts`; create `web/engine/wc/schemas.test.ts`.

**Interfaces:**

- Produces `QualifyingFile`, `WorldCupFile` (+ types), `KnockoutGame`.

Add to `types.ts` (after `ResultsFile`; zod object style as the file does):

```ts
export const QualifyingFile = z.object({
  league: z.literal('fbawc'),
  season: int,
  /** Host country's fbawc teamId (the S{season+1} host). */
  host: z.string().min(1),
  auto: z.array(z.string().min(1)).length(15),
  /** The 70 teams that play qualifying. */
  field: z.array(z.string().min(1)).length(70),
  schedule: z.array(ScheduleGame),
  /** Random tiebreak key per field team, drawn once. */
  keys: z.record(z.string(), z.number()),
  games: z.array(GameResult),
  /** The 49 advancing teams; empty until finished. */
  advanced: z.array(z.string().min(1)),
}).strict().superRefine((d, ctx) => {
  if (d.advanced.length !== 0 && d.advanced.length !== 49) ctx.addIssue({ code: z.ZodIssueCode.custom, message: 'advanced must be empty or 49 teams' });
  if (new Set([...d.auto, ...d.field]).size !== 85) ctx.addIssue({ code: z.ZodIssueCode.custom, message: 'auto and field must be 85 distinct teams' });
});

export const KnockoutRound = z.enum(['R32', 'R16', 'QF', 'SF', 'F']);
export const KnockoutGame = z.object({
  id: z.string().min(1),           // e.g. 'R32-1' .. 'R32-16', 'R16-1' .. 'F-1'
  round: KnockoutRound,
  home: z.string().min(1).nullable(),
  away: z.string().min(1).nullable(),
  game: GameResult.nullable(),
}).strict();

export const WorldCupFile = z.object({
  league: z.literal('fbawc'),
  season: int,
  host: z.string().min(1),
  field: z.array(z.string().min(1)).length(64),
  /** Four pots of 16, best rating first within each. */
  pots: z.array(z.array(z.string().min(1)).length(16)).length(4),
  /** Groups 'A'..'P', four teams each. */
  groups: z.record(z.string().regex(/^[A-P]$/), z.array(z.string().min(1)).length(4)),
  keys: z.record(z.string(), z.number()),
  schedule: z.array(ScheduleGame),
  groupGames: z.array(GameResult),
  /** Empty until the group stage is finished. */
  knockout: z.array(KnockoutGame),
  champion: z.string().min(1).nullable(),
  runnerUp: z.string().min(1).nullable(),
}).strict();
```

`[new RegExp(`^leagues/fbawc/${S}/qualifying\\.json$`), QualifyingFile]`, `[new RegExp(`^leagues/fbawc/${S}/worldcup\\.json$`), WorldCupFile]`.

### Task 3: Country rating and roster derivation

**Files:** Create `web/engine/wc/rating.ts`, `roster.ts`, `rating.test.ts`, `roster.test.ts`.

**Interfaces:**
- Consumes: `CITY_COUNTRY` (Task 1), `RosterEntry`, `RostersFile`, `Position` (types), `randInt`, `Rng`.
- Produces:
```ts
// rating.ts
export function countryRating(roster: RosterEntry[]): number; // average of the five ratings (null rating counts as 0)

// roster.ts
export const GENERATED_AGE = 31;
export interface DeriveInput {
  /** All 85 fbawc team ids. */
  countries: string[];
  /** The current season's FBAD2 rosters. */
  d2Rosters: RostersFile;
  mode: 'qualifying' | 'worldcup';
  /** Previous season's fbawc rosters (needed for 'worldcup' carry-over); null otherwise. */
  previous: RostersFile | null;
}
export function deriveRosters(input: DeriveInput, rng: Rng): Record<string, RosterEntry[]>;
```

Rules:
- Each country's roster has exactly 5 entries, order PG, SG, SF, PF, C, each `{ playerId, position, rating, age, points: 0 }`.
- Real: among entries of `d2Rosters.teams[d2Id]` for the country's cities (`d2CitiesOf`), the best at each position: highest `rating`, then lowest `age`, then lowest `playerId` (string compare). Skip entries with `playerId === null` or `rating === null`.
- Missing position, mode `qualifying`: generated `{ playerId: null, position, rating: randInt(rng, 65, 74), age: 31, points: 0 }`. Draw in a fixed order (countries in input order, positions PG..C) so the result is deterministic.
- Missing position, mode `worldcup`: take the entry with that position and `playerId === null` from `previous.teams[country]` and return it with `age + 1`; if none exists, draw a new generated one (age 31 + 1 = 32 is not applied to fresh draws: use age 31). A real player now available always wins.
- `deriveRosters` does not mutate its inputs.

- [ ] **Step 1: Tests (RED).** Fixture: small `d2Rosters` with two English cities (LON, MAN) each with 5 players; assert ENG gets the best at each position, tie broken by younger then lower id. A country with no cities (`ALG`) gets five generated entries with playerId null, rating in 65..74, age 31, positions in order. A country with a city that has only PG/SG gets 3 generated. Same seed ⇒ identical output; different seed ⇒ different generated ratings. `worldcup` mode: carry-over from `previous` with age 32 and same rating; a real player replaces the generated slot; fresh draw when `previous` lacks one. Inputs not mutated (deep-freeze or compare JSON before/after). `countryRating` averages (e.g. 70,72,68,74,66 → 70).
- [ ] **Step 2:** RED; **Step 3:** implement; **Step 4:** pass, tsc clean.
- [ ] **Step 5:** Commit `feat(wc): country rating and roster derivation`.

### Task 4: Table ranking with tiebreaks

**Files:** Create `web/engine/wc/tiebreak.ts`, `tiebreak.test.ts`.

**Produces:**
```ts
export interface WcRow { teamId: string; w: number; l: number; pf: number; pa: number }
export interface WcTable { rows: WcRow[]; ties: string[] }  // rows best first; ties = plain-English notes
export function rankTable(teams: string[], games: GameResult[], keys: Record<string, number>): WcTable;
```
Rules: tally from `games` (only games whose `home` and `away` are both in `teams`). Order by wins desc. For each run of teams tied on wins: if all pairs in the run have played each other, order by head-to-head wins among the run (a sub-tie on h2h wins continues to the next step); else skip h2h. Then point differential (`pf - pa`) desc, then `keys[teamId]` asc (a missing key counts as 0). Add one note per resolved tie, e.g. `"ENG over FRA: head-to-head 1–0"`, `"... point differential +12 vs +5"`, `"... random draw"`.

- [ ] **Step 1: Tests (RED).** Table with a clear winner order; two-way tie broken by h2h; three-way tie where one pair has not played skips h2h and falls to differential; differential tie falls to key; unplayed teams appear with 0–0; games outside `teams` ignored; deterministic.

**Files:** Create `web/engine/wc/state.ts`, `qualifying.ts`, `qualifying.test.ts`.

**Interfaces:**

- Produces `state.ts`:
```ts
export const qualifyingStepId = (season: number) => `s${season}-qualifying`;
export const worldCupStepId = (season: number) => `s${season}-world-cup`;
export type WcResult<S> = { ok: true; state: S; changed: string[]; label: string } | { ok: false; problems: string[] };
export const wcFail = (problems: string[]): { ok: false; problems: string[] } => ({ ok: false, problems });
/** Five players in PG..C order from a roster, ids `<teamId>:<position>` for generated ones. */
```

and `qualifying.ts`:
```ts
export interface QualifyingState { calendar: CalendarFile; rosters: RostersFile; qualifying: QualifyingFile | null }
export function startQualifying(
  input: { season: number; calendar: CalendarFile; d2Rosters: RostersFile; countries: string[]; host: string; previousWc: RostersFile | null },
  rng: Rng,
): WcResult<QualifyingState>;
export function playQualifyingGame(state: QualifyingState, rng: Rng): WcResult<QualifyingState>;      // next unplayed game
export function finishQualifying(state: QualifyingState): WcResult<QualifyingState>;                   // sets advanced, marks calendar step done
export function qualifyingTable(q: QualifyingFile): WcTable;                                            // rankTable over q.field
export function sixRegularPairs(ids: string[], rng: Rng): [string, string][];                          // exported for tests
```
`startQualifying` needs `calendarProblem(calendar, qualifyingStepId(season), 'Qualifying is started')` to be null; refuses if `qualifying` already exists is handled by the caller passing no state (this move only creates). It derives rosters (`mode: 'qualifying'`; `previousWc` unused but kept null) and returns `rosters` as a `RostersFile` `{league:'fbawc', season, locked: true, teams}`. Ranking: by `countryRating` desc; ties by `randInt`-free stable rule: draw a random key per country with `rng()` first and sort by (rating desc, key asc). Top 15 = auto; if `host` not in the top 15, auto = top 14 + host, and the former #15 joins the field. Field = remaining 70 (sorted by id for stable order before pairing).

`sixRegularPairs`: shuffle ids; circulant graph (i↔i+1, i+2, i+3 mod n) gives 6-regular; then 200 random swaps: pick two disjoint edges (a,b),(c,d) at random, replace by (a,d),(c,b) only if that creates no self-loop and no existing edge. Return 210 distinct pairs (for n=70). Schedule: pairs listed in the generated order but arranged into rounds greedily so no team appears twice in a round (14 rounds? a 6-regular graph on 70 vertices needs ≥6 rounds; greedy is fine; just keep the order sorted by round). `home` is the first of each pair. Game numbers 1..210.

`playQualifyingGame`: next game = `schedule[games.length]`; refuse if none, or step isn't current (`calendarProblem(..., 'Qualifying is played')`). Sim with `simGame(gameNo, simTeam(home, roster), simTeam(away, roster), rng)` then `toGameResult`.

`finishQualifying`: refuse unless all 210 played and not yet finished; `advanced` = first 49 of `qualifyingTable`; marks the step done via `markStepDone`; label e.g. "Qualifying finished: 49 advance".

(b) `startQualifying` with 85 countries given ratings via a synthetic `d2Rosters` (countries with cities get ratings, others generated): auto has 15; host inside top 15 keeps the top 15; host outside replaces #15 and the old #15 is in `field`; auto∪field = 85 distinct; `schedule` has 210 games; step must be current (refuse when the calendar's current step is something else); `QualifyingFile.safeParse` passes; rosters file has 85 teams of 5. ### Task 6: World Cup engine

**Files:** Create `web/engine/wc/worldcup.ts`, `worldcup.test.ts`.

**Interfaces:**
- Consumes: Tasks 2–5 (`WorldCupFile`, `deriveRosters`, `countryRating`, `rankTable`, `simTeam`, `winnerOf`, `WcResult`, `worldCupStepId`), `shuffle`.
- Produces:
```ts
export interface WorldCupState { calendar: CalendarFile; rosters: RostersFile; worldCup: WorldCupFile | null }
export function startWorldCup(
  input: { season: number; calendar: CalendarFile; d2Rosters: RostersFile; countries: string[]; qualifying: QualifyingFile; previous: RostersFile },
  rng: Rng,
): WcResult<WorldCupState>;
export function playGroupGame(state: WorldCupState, rng: Rng): WcResult<WorldCupState>;
export function groupTable(wc: WorldCupFile, group: string): WcTable;
export function finishGroups(state: WorldCupState): WcResult<WorldCupState>;     // builds the knockout
export function playKnockoutGame(state: WorldCupState, rng: Rng): WcResult<WorldCupState>;   // next playable game, earliest round first
export function finishWorldCup(state: WorldCupState): WcResult<WorldCupState>;   // marks the calendar step done once champion is set
```
Rules:
- `startWorldCup`: step must be current (`calendarProblem(..., worldCupStepId(season), 'The World Cup is started')`); `qualifying.advanced` must have 49. Field = `auto ∪ advanced` (64). Rosters re-derived with `mode: 'worldcup'`, `previous` = previous season's rosters; result `RostersFile {league:'fbawc', season, locked: true, teams}`. Ratings → sort desc (ties by a random key from `rng()` drawn per field team in sorted-id order; store as `keys`) → pots of 16. Groups: for each pot, shuffle its teams and assign pot team k to group k (A..P); the host is first moved to group A within its pot (swap with whoever got A). Schedule: for each group, a double round robin of its 4 teams (6 rounds: 3 rounds of round robin, then the same 3 reversed home/away), games numbered 1..192 in round order (all groups' round 1, then round 2 …).
- `playGroupGame`: plays `schedule[groupGames.length]`, refuses when none left or step not current.
- `groupTable`: `rankTable(groups[g], groupGames, keys)`.
- `finishGroups`: requires 192 games played and `knockout` empty. R32 pairs in this order (ids `R32-1`..`R32-16`): A1–B2, C1–D2, E1–F2, G1–H2, I1–J2, K1–L2, M1–N2, O1–P2, B1–A2, D1–C2, F1–E2, H1–G2, J1–I2, L1–K2, N1–M2, P1–O2 (home = group winner). Then empty later rounds: `R16-1..8` (null teams), `QF-1..4`, `SF-1..2`, `F-1`.
- `playKnockoutGame`: finds the first game (round order, then id order) with both teams set and `game: null`; sims it (continuing `gameNo` after the group games: 193…), stores it; the winner fills the next round's slot: R32-(2k-1)/(2k) → R16-k as home/away, same pattern up to `F-1`. Refuses when no game is playable or the step isn't current. When `F-1` finishes, sets `champion` and `runnerUp`.
- `finishWorldCup`: requires `champion` set; marks the step done via `markStepDone`; label "World Cup finished: <champion>". (Writing `summary.json` is deferred to 5c: it needs the MVP.)

- [ ] **Step 1: Tests (RED).** Build `QualifyingFile` + `RostersFile` fixtures from a helper that runs the real Task 5 flow with a seeded Rng, or hand-built with 15+49 teams. Assert: 64 distinct teams; 4 pots of 16; every group has one team from each pot; host in group A; 12 games per group, each ordered pair twice, 192 total; `WorldCupFile.safeParse` passes; `groupTable` ordering; refusal when out of order or when qualifying isn't finished; `finishGroups` refused early; R32 pairing matches the order above (winner of A vs runner-up of B in `R32-1`); winners advance correctly through all rounds; after 31 knockout games champion and runnerUp are set and differ; finish marks the step done; same seed ⇒ identical document.
