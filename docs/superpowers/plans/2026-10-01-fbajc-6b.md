# FBAJC 6b (postseason) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play the FBAJC postseason in the web app: 18 conference tournaments, the NIT and March Madness fields (Java logic, with regular-season champions guaranteed an NIT place), awards picked before the tournaments, the NIT, then March Madness, All-American teams, the two C-Ship MVPs, and the season summary that finishes the `fbajc` calendar step.

**Architecture:** Pure TypeScript under `web/engine/jc/` (continuing 6a), every random choice through an injected `Rng`. Postseason games reuse `simGame`/`toGameResult`. Two new saved docs per season, `postseason.json` and `awards.json`; the season record goes into the existing `summary.json`. Pages under `web/app/jc/`.

**Tech Stack:** TypeScript 5, zod 3 (strict), React 18, React Router 6, Vitest 2 (globals off).

Spec: `docs/superpowers/specs/2026-10-01-fbajc-6b-design.md` (read it first, then `2026-10-01-fbajc-design.md`). Java reference (read-only): `FBAJC/src/fbajc/` (`PostSeasonTourny.java`, `MarchMadness.java` lines 45–560, `NIT.java`, `Main.java` lines 3300–3500 for the awards). Part 6a is merged: read `engine/jc/{state,play,standings,clinch,rankings}.ts` and `app/jc/` before starting.

- Moves return `{ ok: true, state, changed, label }` or `{ ok: false, problems }` (`JcResult`, `jcFail` in `engine/jc/state.ts`).
- Zod schemas are `.strict()`; each saved doc has a schema in `engine/shared/types.ts` and a path rule in `schemaRegistry.ts`. `web/data.test.ts` must keep passing.
- Saves go through `commitDocs` (`app/roster/commit.ts`) with the loaded versions (missing doc = version null); chained saves use the versions returned by the previous save. Guard saving handlers with a `useRef` (`useSaving()` forces an extra render).
- Every jsdom test file calls `cleanup()` in `afterEach`. Tests sit next to the source. Run RED first.
- A page for a season whose stage doesn't exist must not title itself with the current season. Calendar-driven pages need their `leagueSections` entry in `app/shell/SectionNav.tsx`.
- Rules (spec §2): conference tournaments (12 teams, 11 games, seeds 1–4 bye) → fields → awards → **NIT first**, then March Madness → All-Americans → MVPs → summary. Postseason games do not touch standings. **Ratings progress only in conference tournament games**; points are recorded in every game. March Madness field is the Java loop; NIT = regular-season champions (ties share) that missed March Madness, then best by ranking, 32 in all.

## Data shapes (Task 2 defines them; later tasks use them)

```ts
// A bracket game; home is the first-listed team (no home advantage).
BracketGame = { id: string, round: int /*1-based within the bracket*/, region: int /*0-3 for MM/NIT regions, 0 otherwise*/,
  home: string|null, away: string|null, homeSeed: int|null, awaySeed: int|null,
  next: { id: string, side: 'home'|'away' } | null,        // where the winner goes; null for the final
  result: GameResult | null }                              // existing GameResult (with box lines)
Bracket = { id: string, kind: 'conf'|'mm'|'nit', name: string, games: BracketGame[], champion: string|null }

// leagues/fbajc/S<n>/postseason.json
JcPostseasonFile = { league: 'fbajc', season: int, locked: boolean,
  nextGameNo: int,                                         // postseason games are numbered from 3133
  conf: Bracket[],                                         // 18, id = conference code (teams.json group)
  rsChampions: Record<string, string[]>,                   // conference -> team ids sharing the best conference record
  field: null | { mm: { teams: string[64] /*field order*/, seeds: Record<string,int>, regions: string[][] /*4 x 16, Java region order*/ },
                  nit: { teams: string[32] /*seed order*/ }, warnings: string[] },
  nit: Bracket|null, mm: Bracket|null }

// leagues/fbajc/S<n>/awards.json
JcAwardsFile = { league: 'fbajc', season: int, locked: boolean,
  national: { award: 'POY'|'FOY'|'GOY'|'FWD'|'COY'|'DPOY', playerId: string|null }[],   // 6 entries
  conference: { conf: string, playerId: string|null }[],                                 // 18 entries
  allAmerican: null | { team: 1|2|3, slots: { slot: 'G'|'F'|'C'|'ANY', playerId: string|null }[] /*5: G,F,C,ANY,ANY*/ }[],
  mvp: { mm: string|null, nit: string|null } }
```

The summary (`SummaryFile`) gains an optional `jc` object (Task 2): conference tournament and regular-season champions, national and conference awards, All-American teams, MVPs, NIT champion and runner-up, and `pastBracket` for March Madness.
